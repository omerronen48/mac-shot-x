# Roadmap: MacShot v2 — Feature Parity with sw33tLie/macshot

Extends the shipped v1 (M1–M6: capture, overlay/history, editor, beautify, OCR, ship) toward
parity with the reference app `com.sw33tlie.macshot` v4.2.1. Same principles: native Swift/SwiftUI,
`MacShotCore` holds headless-testable logic (strict TDD), the AppKit/SwiftUI shell is thin and
manually verified. Milestones are ordered small→large; the big categories (recording, cloud,
translation, i18n) get their own brainstorm+plan and are **not** blind-parallelized.

## Vision (v2 delta)

Close the gap with the reference app: capture conveniences, editor/OCR parity, screen recording,
cloud upload/sharing, live translation, AI redaction, scrolling capture, and localization —
while keeping the "still works fully offline; nothing leaves the device unless you ask" stance
(cloud upload is opt-in and user-initiated).

## Tech stack additions (rationale)

| Choice | For | Rationale |
|---|---|---|
| ScreenCaptureKit `SCStream` (video) | recording | already used for stills; same TCC grant, native H.264/HEVC |
| `AVAssetWriter` / `AVAssetExportSession` | recording export, GIF/WebP | native encode; GIF via `CGImageDestination` (`com.compuserve.gif`) |
| Vision `VNDetectBarcodesRequest` | QR/barcode | on-device, zero-dep, sits beside existing OCR |
| `Translation` framework (macOS 15+) w/ graceful fallback | live translation | on-device Apple translation; degrade if <15 |
| `AVCaptureSession` | webcam overlay | native camera |
| Sparkle 2 (SPM) | auto-update | replaces the hand-rolled checker; signed appcast (optional, evaluated in M10) |
| `AWSS3`-free raw SigV4 / `URLSession` | S3 upload | avoid heavy SDK; sign requests by hand |
| `String Catalog` (.xcstrings) | i18n | modern localization; base + community strings |

## Non-functional targets (carried from v1 + additions)

- Capture latency unchanged (<100ms to selection UI); recording start <500ms.
- Offline-first: every non-upload feature works with zero network. Uploads are explicit, per-action.
- Memory: recording bounded (stream to disk, no full in-RAM buffering); history smooth at 10k.
- Privacy: no telemetry; cloud credentials stored in Keychain; upload requires confirmation.

## Risks & assumptions

1. **Recording architecture** — `SCStream` frame handling + `AVAssetWriter` back-pressure; retire by M12.
2. **Cloud/OAuth security** — token storage, redirect handling; Google OAuth needs a client id (user supplies). Escalate the provider/credential decisions.
3. **Translation availability** — `Translation` framework is macOS 15+; we target 14+. Decide fallback (skip / bundle nothing / Google API) at M15.
4. **i18n scope** — 41 languages is a lot; M18 ships the framework + English + a small starter set, not hand-translated 41.
5. **Scope creep** — reference app is huge; each milestone's "scope out" is the contract.

## Milestones

### M7 — Capture conveniences

- **Goal:** the small capture-flow niceties the reference app has.
- **Scope in:** self-timer / capture delay with an on-screen countdown; "Capture Last Area" (repeat the previous selection); capture-mouse-cursor toggle; downscale-Retina export option (halve dimensions); re-add a **correct** magnifier loupe (snapshot the screen once at overlay-present, sample that cached image — never `cacheDisplay` in `draw`).
- **Scope out:** recording, editor changes.
- **Already decided:** loupe uses a present-time screen snapshot (v1 lesson); prefs via existing `Preferences`/`KeyValueStore`.
- **Open questions for brainstorming-time:** default delay values, loupe size/zoom defaults, where "Capture Last Area" stores the last rect.
- **Depends on:** M1.
- **Definition of done:** author uses self-timer + capture-last-area daily; loupe aids precise selection with no crash.
- **Hand-off:** `Use brainstorming-time on milestone M7: Capture conveniences`

### M8 — Editor parity (annotation tools)

- **Goal:** bring the editor up to the reference tool set.
- **Scope in:** Line tool; Solid-fill censor (extend blur/pixelate with an opaque redaction); emoji/sticker picker; richer text styling (outline, text background, alignment, size/color menus).
- **Scope out:** AI auto-redact (M16); translation (M15).
- **Already decided:** vector model in `MacShotCore` (extend `AnnotationKind`); renderer extends `AnnotationRenderer`.
- **Open questions for brainstorming-time:** sticker source (emoji only vs bundled set), text-style UI layout.
- **Depends on:** M3.
- **Definition of done:** an annotated image using line + solid-censor + emoji + styled text, produced end-to-end.
- **Hand-off:** `Use brainstorming-time on milestone M8: Editor parity`

### M9 — QR & barcode reading

- **Goal:** capture-to-decoded-payload for QR/barcodes, beside OCR.
- **Scope in:** `VNDetectBarcodesRequest` in the OCR capture flow; detect QR/common barcodes; copy payload to clipboard + notification (open URL payloads optionally).
- **Scope out:** generating codes; translation.
- **Already decided:** Vision, on-device; reuse the M5 OCR capture/selection path.
- **Open questions for brainstorming-time:** OCR vs QR mode (auto-detect both vs separate hotkey), URL-open confirmation.
- **Depends on:** M5.
- **Definition of done:** scan a QR from the screen → payload on clipboard.
- **Hand-off:** `Use brainstorming-time on milestone M9: QR & barcode reading`

### M10 — Settings & menu-bar polish

- **Goal:** settings management + menu-bar customization + updater decision.
- **Scope in:** settings export/import (JSON, excluding secrets/history); configurable menu-bar action order; custom/hideable menu-bar icon (SF Symbol picker); evaluate + optionally migrate the updater to Sparkle 2.
- **Scope out:** cloud settings (M14).
- **Already decided:** settings serialize from `Preferences`; menu order stored as a pref list.
- **Open questions for brainstorming-time:** Sparkle vs keep-hand-rolled (needs a signed appcast); icon picker scope.
- **Depends on:** M1, M6.
- **Definition of done:** export settings, import on a clean install; reorder/hide the menu-bar icon.
- **Hand-off:** `Use brainstorming-time on milestone M10: Settings & menu-bar polish`

### M11 — Pin-to-screen

- **Goal:** pin a screenshot as a floating always-on-top window.
- **Scope in:** "Pin to Screen" action (from overlay/history) → a borderless floating panel of the shot; move/close/opacity; multiple pins.
- **Scope out:** annotation on pinned windows.
- **Already decided:** reuse the `QuickAccessPanel`/NSPanel floating-window pattern.
- **Open questions for brainstorming-time:** pin interactions (drag, resize, opacity), persistence across relaunch.
- **Depends on:** M2.
- **Definition of done:** pin a reference image on screen while working; it stays on top.
- **Hand-off:** `Use brainstorming-time on milestone M11: Pin-to-screen`

### M12 — Screen recording (core)

- **Goal:** record the screen/area/window to a video file.
- **Scope in:** `SCStream` video capture (screen/area/window); recording HUD panel (stop/pause/timer); pre-record countdown; recording settings (fps, area, when-done action); export MP4; convert to **GIF** and **WebP**.
- **Scope out:** webcam/keystroke overlays + video editor (M13).
- **Already decided:** ScreenCaptureKit `SCStream` + `AVAssetWriter`; stream to disk.
- **Open questions for brainstorming-time (ESCALATE if unresolved):** container/codec defaults, GIF frame-rate/scale, HUD placement.
- **Depends on:** M1.
- **Definition of done:** record a 30s screen clip → MP4 + GIF that plays.
- **Hand-off:** `Use brainstorming-time on milestone M12: Screen recording core`

### M13 — Recording overlays & video editor

- **Goal:** the recording extras the reference app has.
- **Scope in:** webcam overlay (`AVCaptureSession` PiP); keystroke overlay; click highlighting; a light video editor (trim, freeze segment, text segment, speed factor).
- **Scope out:** multi-track editing.
- **Already decided:** overlays composited into the `SCStream` output; editor via `AVMutableComposition`.
- **Open questions for brainstorming-time:** overlay positioning/config, editor scope.
- **Depends on:** M12.
- **Definition of done:** a recording with a webcam bubble + visible keystrokes, trimmed and exported.
- **Hand-off:** `Use brainstorming-time on milestone M13: Recording overlays & editor`

### M14 — Cloud upload & sharing

- **Goal:** opt-in upload + link sharing.
- **Scope in:** macOS Share Sheet; imgbb/imgur (API key); S3 (custom endpoint, SigV4); Google Drive (OAuth); copy public link; confirm-before-upload; Keychain-stored credentials.
- **Scope out:** account sync, teams.
- **Already decided:** uploads are explicit + confirmed; secrets in Keychain; each provider behind a `Uploader` protocol.
- **Open questions for brainstorming-time (ESCALATE):** which providers to actually ship first; Google OAuth client id (user must supply); privacy copy.
- **Depends on:** M1.
- **Definition of done:** capture → upload to one provider → public link on clipboard.
- **Hand-off:** `Use brainstorming-time on milestone M14: Cloud upload & sharing`

### M15 — Live translation overlay

- **Goal:** capture text region → translate → overlay translation on the image.
- **Scope in:** OCR the region (M5) → translate (Apple `Translation` framework, macOS 15+) → render translated text over the source layout; copy translated text.
- **Scope out:** document translation.
- **Already decided:** reuse OCR; on-device translation preferred.
- **Open questions for brainstorming-time (ESCALATE):** macOS 15+ requirement vs a fallback provider; overlay layout fidelity.
- **Depends on:** M5, M9.
- **Definition of done:** translate a foreign-language screenshot in place.
- **Hand-off:** `Use brainstorming-time on milestone M15: Live translation overlay`

### M16 — AI auto-redact

- **Goal:** auto-detect + censor sensitive data in a capture.
- **Scope in:** detect emails/phones/cards/keys (Vision text + regex/`NSDataDetector`) → auto-apply solid/blur censor over matches; user reviews before export.
- **Scope out:** face detection redaction (optional later).
- **Already decided:** on-device; reuse M8 censor + M5 OCR observations.
- **Open questions for brainstorming-time:** which PII classes by default, review UX.
- **Depends on:** M5, M8.
- **Definition of done:** a screenshot of a form → sensitive fields auto-censored.
- **Hand-off:** `Use brainstorming-time on milestone M16: AI auto-redact`

### M17 — Scrolling capture

- **Goal:** capture content taller than the screen.
- **Scope in:** auto-scroll (synthetic scroll events) + stitch frames into one tall image; manual mode fallback.
- **Scope out:** horizontal scrolling.
- **Already decided:** synthetic `CGEvent` scroll + image stitching in `MacShotCore` (stitching is testable).
- **Open questions for brainstorming-time:** stitch overlap detection, target-window selection.
- **Depends on:** M1.
- **Definition of done:** capture a full long webpage into one image.
- **Hand-off:** `Use brainstorming-time on milestone M17: Scrolling capture`

### M18 — Localization (i18n)

- **Goal:** make MacShot translatable and ship a starter set.
- **Scope in:** migrate all UI strings to a String Catalog (`.xcstrings`); base English + a small starter set of languages; locale-aware formatting.
- **Scope out:** hand-translating all 41 languages (framework + community-ready, not full translation).
- **Already decided:** `.xcstrings`; do this LAST (touches every UI surface built in M7–M17).
- **Open questions for brainstorming-time:** which starter languages, pseudo-localization for QA.
- **Depends on:** M7–M17 (all UI present).
- **Definition of done:** switch macOS to another language → MacShot's UI follows (for the starter set).
- **Hand-off:** `Use brainstorming-time on milestone M18: Localization`

## Sequencing notes

- **M7–M11** are small→medium, mostly parallel-friendly *within* each milestone's plan. Do first.
- **M12–M17** are the large, design-heavy categories — each gets a full brainstorm; some open questions are flagged ESCALATE (recording defaults, cloud providers/credentials, translation OS floor).
- **M18 last** — localization is cross-cutting and should follow all UI work.
