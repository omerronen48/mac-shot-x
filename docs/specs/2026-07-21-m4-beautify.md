## Purpose

Turn a plain (optionally annotated) capture into a share-ready image: a padded, rounded, shadowed screenshot on a colored/gradient/image background. Applied **only at export** (non-destructive). Definition of done: a one-click pretty screenshot posted publicly.

## Scope

**In:** background (solid color / linear gradient / image), padding, rounded corners, drop shadow, saved presets (with a built-in set), export size (scale) options, live preview in the editor, and the export pipeline that composites beautify over the flattened annotation image.

**Out (the contract):** device-frame mockups, watermarks, per-edge padding asymmetry, AI backgrounds, OCR (M5). Beautify is export-only — it never mutates the base capture or the annotation document.

## Architecture

Stacks on M3. Beautify lives in the editor. All compositing logic in **MacShotCore** (CGContext is headless).

**MacShotCore (new):**
- `BeautifyBackground` — `.solid(RGBAColor)`, `.linearGradient(colors: [RGBAColor], angle: Double)`, `.image(path: String)`. Codable, Equatable.
- `BeautifyShadow` — `{ color: RGBAColor, radius: Double, opacity: Double, offset: CGSize }`. Codable.
- `BeautifyStyle` — `{ background: BeautifyBackground, padding: Double, cornerRadius: Double, shadow: BeautifyShadow?, scale: Double }`. Codable, Equatable. `.none` static = `padding 0, .solid(clear), no shadow, scale 1` → renders a passthrough.
- `BeautifyRenderer.render(image: CGImage, style: BeautifyStyle) -> CGImage` — canvas `(w+2·padding)·scale × (h+2·padding)·scale`; scales the CTM by `scale`; fills the background (`CGGradient` for gradient, aspect-fill draw for `.image`, solid fill otherwise); draws the source inset by `padding` inside a rounded-rect clip with `ctx.setShadow(offset:blur:color:)` when a shadow is set. `.none`/zero-padding returns the base unchanged in size.
- `BeautifyPreset` — `{ name: String, style: BeautifyStyle }`. Codable.
- `PresetStore` — over the M1 `KeyValueStore` (like `PinStore`): `presets() -> [BeautifyPreset]` (built-ins merged with saved), `save(_:)`, `delete(name:)`. `BeautifyStyle.builtins` = None / White / Dark / Blue gradient / Purple gradient / Sunset gradient.

**MacShot shell (new/modified, manual gate):**
- `BeautifyPanel` (new) — SwiftUI controls bound to `EditorViewModel.beautifyStyle`: background type segmented control + color/gradient pickers + image chooser (`NSOpenPanel`), padding slider, corner-radius slider, shadow toggle + radius/opacity/offset, a preset dropdown (Load / "Save current as…" / Delete via `PresetStore`), and an export-scale picker (1×/2×/3×).
- `EditorCanvas` (modify) — renders the live beautify frame (background + padding + rounded corners + shadow) around the annotated image, driven by `vm.beautifyStyle`.
- `EditorViewModel` (modify, in EditorCanvas.swift) — add `beautifyStyle: BeautifyStyle = .none` + a `presetStore`.
- `EditorWindow` (modify) — host `BeautifyPanel`; change `onExport` to `BeautifyRenderer.render(AnnotationRenderer.flatten(base, vm.document), vm.beautifyStyle)` before `sink.copyToClipboard` + `writePNG(mode: "beautified")`.

## Data flow

editor open (M3) → user opens Beautify panel → edits `vm.beautifyStyle` (or loads a preset) → `EditorCanvas` live-previews the framed result → **Export**: `AnnotationRenderer.flatten(base, doc)` → `BeautifyRenderer.render(_, style)` → `SystemSink.copyToClipboard` + `writePNG(mode "beautified")` into the save dir (new file; base + annotations untouched).

## Interfaces

- **CoreGraphics** — `CGGradient`, `ctx.setShadow`, rounded-rect clip; bitmap context for the composite.
- **M3** — `AnnotationRenderer.flatten` (first stage of the export pipeline).
- **M1** — `SystemSink` (clipboard + PNG), `FilenameFormatter`, `Preferences` (save dir).
- **UserDefaults** — presets via `PresetStore`/`KeyValueStore`.

## Error handling

- `.image` background path missing/unreadable → fall back to a solid neutral background; no crash.
- Padding 0 + `.none` background → passthrough render equal in size to the source (still a valid export).
- Preset name collision on save → overwrite the same-named preset (last write wins); built-ins are read-only (a save under a built-in name creates a user copy that shadows it, delete restores the built-in).
- Export scale × huge capture → cap the output's longest side at a safe max (e.g. 8192px) to avoid pathological memory; log if clamped.
- Gradient with <2 colors → treat as solid (first color, or clear if empty).

## Testing

Unit (`swift test`, headless TDD-before-commit):
- `BeautifyRenderer`: output size == `(w+2·padding)·scale × (h+2·padding)·scale`; corner pixel (0,0) equals the background color (solid case); with a shadow, a pixel in the padding band adjacent to the image edge differs from the plain background; `.none` (padding 0) → output size == source size.
- `PresetStore`: built-ins present by default; `save` then `presets()` includes it; `delete` removes a saved one; roundtrip through an in-memory store; `BeautifyStyle`/`BeautifyPreset` Codable roundtrip.
- Gradient degenerate cases: empty/1-color → solid fallback (no crash, deterministic pixel).

Manual (human DoD): open editor → Beautify panel; try each background type, padding, corners, shadow; save + load + delete a preset; switch export scale; Export → a beautified PNG in the save dir + clipboard; post it publicly. Confirm base/annotations unchanged (non-destructive).
